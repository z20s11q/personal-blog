错误分两类：

- 可恢复：如文件不存在。报告给用户并重试。
- 不可恢复：如数组越界，是 bug 的症状，立刻终止程序。

Rust 没有异常。可恢复错误用 `Result<T, E>`，不可恢复用 `panic!`。编译器要求你正视错误，而不是留到生产环境。

本章先讲 `panic!`，再讲返回 `Result<T, E>`，以及何时恢复、何时终止。

**对照**：Java 受检异常、Go 的 `error` 返回值、Python / C++ 异常都在运行期处理；Rust 把「可能失败」写进类型，由编译器检查。

本节是 Rust 语法速查：运算符，以及出现在路径、泛型、trait 约束、宏、属性、注释、元组和括号里的符号。

### 运算符

表 B-1 列出运算符、用例、含义，以及可否重载（可重载的给出对应 trait）。

**表 B-1** 运算符

| 运算符                  | 示例                                                 | 含义                                                           | 可重载?  |
| ----------------------- | ---------------------------------------------------- | -------------------------------------------------------------- | -------- |
| `!`                     | `ident!(...)`, `ident!{...}`, `ident![...]`          | 宏展开                                                          |          |
| `!`                     | `!expr`                                              | 按位或逻辑取反                                                  | `Not`          |
| `!=`                    | `expr != expr`                                       | 不等比较                                                        | `PartialEq`    |
| `%`                     | `expr % expr`                                        | 取余                                                            | `Rem`          |
| `%=`                    | `var %= expr`                                        | 取余并赋值                                                      | `RemAssign`    |
| `&`                     | `&expr`, `&mut expr`                                 | 借用                                                            |          |
| `&`                     | `&type`, `&mut type`, `&'a type`, `&'a mut type`     | 借用指针类型                                                    |          |
| `&`                     | `expr & expr`                                        | 按位与                                                          | `BitAnd`       |
| `&=`                    | `var &= expr`                                        | 按位与并赋值                                                    | `BitAndAssign` |
| `&&`                    | `expr && expr`                                       | 短路逻辑与                                                      |          |
| `*`                     | `expr * expr`                                        | 乘法                                                            | `Mul`          |
| `*=`                    | `var *= expr`                                        | 乘并赋值                                                        | `MulAssign`    |
| `*`                     | `*expr`                                              | 解引用                                                          | `Deref`        |
| `*`                     | `*const type`, `*mut type`                           | 裸指针                                                          |          |
| `+`                     | `trait + trait`, `'a + trait`                        | 复合类型约束                                                    |          |
| `+`                     | `expr + expr`                                        | 加法                                                            | `Add`          |
| `+=`                    | `var += expr`                                        | 加并赋值                                                        | `AddAssign`    |
| `,`                     | `expr, expr`                                         | 参数与元素分隔符                                                |          |
| `-`                     | `- expr`                                             | 取负                                                            | `Neg`          |
| `-`                     | `expr - expr`                                        | 减法                                                            | `Sub`          |
| `-=`                    | `var -= expr`                                        | 减并赋值                                                        | `SubAssign`    |
| `->`                    | `fn(...) -> type`, <code>&vert;...&vert; -> type</code> | 函数与闭包返回类型                                              |          |
| `.`                     | `expr.ident`                                         | 字段访问                                                        |          |
| `.`                     | `expr.ident(expr, ...)`                              | 方法调用                                                        |          |
| `.`                     | `expr.0`, `expr.1`, 等                               | 元组索引                                                        |          |
| `..`                    | `..`, `expr..`, `..expr`, `expr..expr`               | 右开区间字面量                                                  | `PartialOrd`   |
| `..=`                   | `..=expr`, `expr..=expr`                             | 右闭区间字面量                                                  | `PartialOrd`   |
| `..`                    | `..expr`                                             | 结构体字面量更新语法                                            |          |
| `..`                    | `variant(x, ..)`, `struct_type { x, .. }`            | 「其余」模式绑定                                                |          |
| `...`                   | `expr...expr`                                        | (已废弃，改用 `..=`) 模式中的闭区间模式                          |          |
| `/`                     | `expr / expr`                                        | 除法                                                            | `Div`          |
| `/=`                    | `var /= expr`                                        | 除并赋值                                                        | `DivAssign`    |
| `:`                     | `pat: type`, `ident: type`                           | 约束                                                            |          |
| `:`                     | `ident: expr`                                        | 结构体字段初始化                                                |          |
| `:`                     | `'a: loop {...}`                                     | 循环标签                                                        |          |
| `;`                     | `expr;`                                              | 语句与项终结符                                                  |          |
| `;`                     | `[...; len]`                                         | 定长数组语法的一部分                                            |          |
| `<<`                    | `expr << expr`                                       | 左移                                                            | `Shl`          |
| `<<=`                   | `var <<= expr`                                       | 左移并赋值                                                      | `ShlAssign`    |
| `<`                     | `expr < expr`                                        | 小于比较                                                        | `PartialOrd`   |
| `<=`                    | `expr <= expr`                                       | 小于等于比较                                                    | `PartialOrd`   |
| `=`                     | `var = expr`, `ident = type`                         | 赋值 / 等价                                                     |          |
| `==`                    | `expr == expr`                                       | 相等比较                                                        | `PartialEq`    |
| `=>`                    | `pat => expr`                                        | match 分支语法的一部分                                          |          |
| `>`                     | `expr > expr`                                        | 大于比较                                                        | `PartialOrd`   |
| `>=`                    | `expr >= expr`                                       | 大于等于比较                                                    | `PartialOrd`   |
| `>>`                    | `expr >> expr`                                       | 右移                                                            | `Shr`          |
| `>>=`                   | `var >>= expr`                                       | 右移并赋值                                                      | `ShrAssign`    |
| `@`                     | `ident @ pat`                                        | 模式绑定                                                        |          |
| `^`                     | `expr ^ expr`                                        | 按位异或                                                        | `BitXor`       |
| `^=`                    | `var ^= expr`                                        | 按位异或并赋值                                                  | `BitXorAssign` |
| <code>&vert;</code>       | <code>pat &vert; pat</code>                             | 模式备选                                                        |          |
| <code>&vert;</code>       | <code>expr &vert; expr</code>                           | 按位或                                                          | `BitOr`        |
| <code>&vert;=</code>      | <code>var &vert;= expr</code>                           | 按位或并赋值                                                    | `BitOrAssign`  |
| <code>&vert;&vert;</code> | <code>expr &vert;&vert; expr</code>                     | 短路逻辑或                                                      |          |
| `?`                     | `expr?`                                              | 错误传播                                                        |          |

### 非运算符符号

以下符号不充当运算符，行为不像函数或方法调用。

表 B-2：独立出现的符号。

**表 B-2** 独立语法

| 符号                                                                 | 含义                                                            |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `'ident`                                                               | 命名生命周期或循环标签                                           |
| 数字紧跟 `u8`、`i32`、`f64`、`usize` 等                                 | 指定类型的数字字面量                                             |
| `"..."`                                                                | 字符串字面量                                                     |
| `r"..."`、`r#"..."#`、`r##"..."##` 等                                  | 原始字符串字面量，不处理转义                                     |
| `b"..."`                                                               | 字节串字面量，构造字节数组而非字符串                             |
| `br"..."`、`br#"..."#`、`br##"..."##` 等                               | 原始字节串字面量，原始与字节串的结合                             |
| `'...'`                                                                | 字符字面量                                                       |
| `b'...'`                                                               | ASCII 字节字面量                                                 |
| <code>&vert;...&vert; expr</code>                                      | 闭包                                                             |
| `!`                                                                    | 发散函数的空底部类型                                             |
| `_`                                                                    | 「忽略」模式绑定；也让整数字面量更易读                           |

表 B-3：路径相关符号。

**表 B-3** 路径相关语法

| 符号                                  | 含义                                                                                                        |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------|
| `ident::ident`                          | 命名空间路径                                                                                                 |
| `::path`                                | 相对 crate 根的路径（显式绝对路径）                                                                          |
| `self::path`                            | 相对当前模块的路径（显式相对路径）                                                                           |
| `super::path`                           | 相对当前模块父模块的路径                                                                                     |
| `type::ident`, `<type as trait>::ident` | 关联常量、函数、类型                                                                                         |
| `<type>::...`                           | 无法直接命名类型的关联项（如 `<&T>::...`、`<[T]>::...`）                                                     |
| `trait::method(...)`                    | 用定义该方法的 trait 消歧                                                                                    |
| `type::method(...)`                     | 用定义该方法的类型消歧                                                                                       |
| `<type as trait>::method(...)`          | 同时用 trait 和类型消歧                                                                                      |

表 B-4：泛型。

**表 B-4** 泛型

| 符号                         | 含义                                                                                                                                                |
| ------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `path<...>`                    | 类型中为泛型指定参数（如 `Vec<u8>`）                                                                                                                |
| `path::<...>`, `method::<...>` | 表达式中为泛型、函数或方法指定参数，俗称 turbofish（如 `"42".parse::<i32>()`）                                                                      |
| `fn ident<...> ...`            | 定义泛型函数                                                                                                                                        |
| `struct ident<...> ...`        | 定义泛型结构体                                                                                                                                      |
| `enum ident<...> ...`          | 定义泛型枚举                                                                                                                                        |
| `impl<...> ...`                | 定义泛型实现                                                                                                                                        |
| `for<...> type`                | 高阶生命周期约束                                                                                                                                     |
| `type<ident=type>`             | 为关联类型指定具体类型的泛型类型（如 `Iterator<Item=T>`）                                                                                            |

表 B-5：trait 约束。

**表 B-5** trait 约束

| 符号                        | 含义                                                                                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `T: U`                        | 泛型参数 `T` 约束为实现了 `U` 的类型                                                                                                        |
| `T: 'a`                       | `T` 必须比 `'a` 活得久（不含生命周期短于 `'a` 的传递性引用）                                                                                |
| `T: 'static`                  | `T` 不含 `'static` 之外的借用                                                                                                               |
| `'b: 'a`                      | `'b` 必须比 `'a` 活得久                                                                                                                     |
| `T: ?Sized`                   | 允许泛型参数是动态大小类型                                                                                                                  |
| `'a + trait`, `trait + trait` | 复合类型约束                                                                                                                                |

表 B-6：宏与属性。

**表 B-6** 宏与属性

| 符号                                      | 含义        |
| ------------------------------------------- | ------------------ |
| `#[meta]`                                   | 外部属性    |
| `#![meta]`                                  | 内部属性    |
| `$ident`                                    | 宏替换 |
| `$ident:kind`                               | 宏元变量 |
| `$(...)...`                                 | 宏重复   |
| `ident!(...)`, `ident!{...}`, `ident![...]` | 宏调用   |

表 B-7：注释。

**表 B-7** 注释

| 符号     | 含义             |
| ---------- | ----------------------- |
| `//`       | 行注释            |
| `//!`      | 内部行文档注释  |
| `///`      | 外部行文档注释  |
| `/*...*/`  | 块注释           |
| `/*!...*/` | 内部块文档注释 |
| `/**...*/` | 外部块文档注释 |

表 B-8：圆括号。

**表 B-8** 圆括号

| 符号                   | 含义                                                                                 |
| ------------------------ | ------------------------------------------------------------------------------------------- |
| `()`                     | 空元组（unit），字面量与类型均可用                                                         |
| `(expr)`                 | 括号表达式                                                                           |
| `(expr,)`                | 单元素元组表达式                                                              |
| `(type,)`                | 单元素元组类型                                                                |
| `(expr, ...)`            | 元组表达式                                                                           |
| `(type, ...)`            | 元组类型                                                                              |
| `expr(expr, ...)`        | 函数调用；也用于初始化元组结构体和元组枚举变体                                          |

表 B-9：花括号。

**表 B-9** 花括号

| 上下文      | 含义      |
| ------------ | ---------------- |
| `{...}`      | 块表达式 |
| `Type {...}` | 结构体字面量   |

表 B-10：方括号。

**表 B-10** 方括号

| 上下文                                            | 含义                                                                                                                          |
| -------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `[...]`                                            | 数组字面量                                                                                                                    |
| `[expr; len]`                                      | 含 `len` 个 `expr` 副本的数组字面量                                                                                           |
| `[type; len]`                                      | 含 `len` 个 `type` 实例的数组类型                                                                                             |
| `expr[expr]`                                       | 集合索引；可重载（`Index`、`IndexMut`）                                                                                       |
| `expr[..]`, `expr[a..]`, `expr[..b]`, `expr[a..b]` | 用 `Range`、`RangeFrom`、`RangeTo`、`RangeFull` 作「索引」的切片式索引                                                         |
